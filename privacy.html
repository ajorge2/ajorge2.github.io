Project privacy

Updated October 24, 2026. These are research demos. Use fictional inputs and check each repository's PRIVACY.md before supplying private data.

  • MCP tools: local tools return selected evidence to your AI client without calling a model or saving request/result content. The public MCP examples expose synthetic data. Your AI client's retention policy still applies.
  • CodeArchitect web: bundled public source only; personal uploads and server-path selection are blocked. Questions/context go to OpenAI. This differs from the local MCP.
  • OrcView web: questions and bundled source go to Anthropic. Configuration/history is private to a temporary browser session. SDK disk recordings require explicit opt-in.
  • DemandMap: fictional records and offline vectors; uploads disabled. Live public NewsAPI calls require an appropriate paid license and are disabled on the current Developer plan.
  • Learning Accelerator: per-browser temporary databases; notes/questions/PDFs go to OpenAI when AI features are used. Shared search is disabled; browser copies use sessionStorage.
  • Markets: restricted ICE/BofA observations are withheld; saved-data changes require operator authorization. Earlier screenshots containing those values were replaced with an illustrative architecture diagram.
  • AgenticETL and VariantGrid: trusted local operator tools that intentionally persist events. Use synthetic events for demonstrations.
  • Brazil analysis and SQLHarness evidence: aggregate/research artifacts; source data and third-party publications retain their own terms.

Hosting providers may retain operational metadata. Some pages load external fonts/assets. Disabling optional provider response storage does not establish zero provider retention. Older Git commits, browser caches, legacy databases/search indexes, and downloaded copies are not erased by a source update.
